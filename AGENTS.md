# AGENTS.md

## Desarrollo

- **Dev**: `npm run dev` (sirve en http://localhost:8080)
- **Lint**: `npm run lint`
- **Build**: `npm run build`
- **Formato**: `npx prettier --write <archivos>`

## Convenciones

- Estética Persona 3 Reload: paleta azul eléctrico/negro, tipografías Bebas Neue + Rajdhani. Sin destellos/glows de color.
- Componentes del portafolio en `src/components/portfolio/` con nombres en español.
- El tema oscuro se aplica por defecto y persiste en `localStorage` (`src/hooks/use-theme.ts`).
